<objective>
Three intertwined deliverables that complete the Phase 2 public API surface:

1. **Streaming exports (API-06):** Add `?format=csv|json|parquet` to `/v1/observations` (NOT a separate URL path — same endpoint, different Accept-like query param). Each format streams the full result set without pagination, never materializes the result set in memory, and stays under 200MB RSS for multi-year queries (ROADMAP success criterion #2).

2. **Rate limiting (API-08 + per-route slice of API-13):** slowapi with Redis DB 2 storage, per-IP + per-route key scheme, 429 + RFC 7807 + X-RateLimit-* headers + Retry-After per D-API-12. Uses the GDPR-truncated IP from plan 02-01 (Pitfall 1 mitigation).

3. **OpenAPI 3.1 enrichment (API-09):** Override `app.openapi()` with `custom_openapi()` injecting the D-API-24 info block, D-API-26 servers list, and D-API-25 x-codeSamples per endpoint. Verify Swagger /docs and Redoc /redoc render without errors against the enriched spec.

Purpose: After this plan the API is feature-complete for v1.0 — researchers can stream multi-year Parquet, dashboard clients are protected from rate-limit abuse via consistent multi-worker Redis-backed counters, and downstream SDK generators (Phase 3 typed ApiClient, future v1.1 openapi-generator) consume a spec rich enough to produce working clients.

Output: Two new router/query modules for exports, two new middleware modules for rate-limit + OpenAPI, updated decorators on all four existing routers (stations/observations/sources/meta) to apply per-route rate-limit decorators, updated main.py wiring.

Vertical MVP framing: This is the final functional plan. Plan 02-06 adds observability + docs without changing any user-visible API behavior.
</objective>

| Boundary | Description |
|----------|-------------|
| Untrusted query param `format=` -> dispatch into streaming generator | Format value is a string; must validate against allowed set BEFORE branching |
| Untrusted IP (raw) -> rate-limit bucket key | Pitfall 1: raw IP in rate-limit key would defeat GDPR truncation in logs |
| Untrusted long-range query -> Parquet streaming | DoS via memory exhaustion if writer is not flushed in 10k batches |
| Untrusted OpenAPI consumer -> /openapi.json | Public surface; no PII; servers list reveals deployment URLs (intentional per D-API-26) |
