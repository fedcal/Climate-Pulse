<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/researcher tool -> FastAPI | Untrusted HTTP requests (preflight + GET) cross here; client IP, headers, query params are all untrusted |
| FastAPI -> Redis | Cursor secret stored here; rate-limit counters (later plan) will live here; only the API process has the redis client handle |
| API process -> structlog | Logged event_dict crosses here; client IP must be truncated BEFORE this boundary (GDPR) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | Cursor token returned to client | mitigate | HMAC-SHA256 via `hmac.compare_digest` (constant-time, V6 ASVS); secret seeded with `nx=True` and rotatable; expired/tampered cursors -> 400 ProblemDetail in later plan |
| T-02-01-02 | Information Disclosure | structlog event_dict containing raw client IP | mitigate | GDPRIPTruncationMiddleware runs BEFORE any router; `request.state.client_ip_truncated` is the only IP value any subsequent middleware/router should bind to structlog context (downstream plans MUST consume this, not `request.client.host`) |
